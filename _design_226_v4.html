v4 改动说明

  • 删除前缀：折叠态与展开态都去掉「此店需要发出：」，通知直接以第一筐开头（更省空间、更直接）
  • 去除黄色：面包筐亮黄 FFD600 → 亮玫红 FF4081——通知里不再有黄色
  • 去除白色：整箱由 v3 的亮白 FFFFFF → 亮紫 D500F9（与 5 筐色、打卡红均不撞色）
  • 颜色全换鲜艳高亮：5 筐（亮橙 FF6D00 / 亮玫红 FF4081 / 亮青 18FFFF / 亮蓝 448AFF / 亮绿 00E676）+ 整箱亮紫 D500F9 + 打卡亮红 FF1744
  • 折叠态单行全量保留：不展开也看到全部 5 筐 + 整箱 + 打卡
  • 大字保留：筐名 1.2 倍 / 数量 1.4 倍加粗（展开态数量 2.0 倍）
  • 整箱数逻辑不变：只取常温筐的整箱数，没填为 0 则不显示
