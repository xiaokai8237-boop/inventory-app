# 物流筐 APP · 全功能交互走查 04 —— 登录 / 注册 / 忘记密码（整页）

> 版本：v8.2.6（2026-08-11 走查）· 逐行读代码核实

---

## 一、三个页面关系

```
登录页 ──「立即注册」──→ 注册页
  ↑                      │
  └────「去登录」─────────┘
登录页 ──「忘记密码？」──→ 忘记密码页 ──「去登录」──→ 登录页
```

进入方式：首页账号胶囊 / 未登录横条 / 邀请页去登录 / 各页面登录按钮。

---

## 二、登录页

### 元素与链路
| # | 控件 | 操作 | 结果 |
|---|------|------|------|
| 1 | × 关闭 | 点击 | 关登录页，回原页面 |
| 2 | 手机号框 | 输入 11 位数字 | - |
| 3 | 密码框 + 眼睛按钮 | 点眼睛 | 明文/密文切换 |
| 4 | 记住账号 | 点击 | 打勾/取消（勾选后下次自动填手机号） |
| 5 | 忘记密码？ | 点击 | 切到忘记密码页 |
| 6 | 登录按钮 | 点击 `doLogin()` | 见下方校验逻辑 |
| 7 | 同意隐私政策勾选 | 点击 | 打勾/取消（不勾不能登录） |
| 8 | 《隐私政策》/《用户协议》 | 点击 | 弹对应协议弹窗 |
| 9 | 立即注册 | 点击 | 切到注册页 |

### 登录按钮校验逻辑（doLogin）
| 情况 | 结果 |
|------|------|
| 手机号格式错 | 提示「请输入正确的11位手机号」 |
| 没勾同意协议 | 提示「请先勾选同意《隐私政策》和《用户协议》」 |
| 密码错试太多被锁 | 提示「尝试次数过多，请 X 分钟后再试」 |
| 密码对 | 登录成功：同步 VIP 到期时间、保存云端数据、**提示「如需要云端数据，请手动点「恢复云端数据」」**（不自动覆盖本地） |
| 密码错 | 提示错误信息 |
| 网络错误 | 提示「网络错误」 |

## 三、注册页

### 元素与链路
| # | 控件 | 操作 | 结果 |
|---|------|------|------|
| 1 | × 关闭 | 点击 | 关注册页回原页面 |
| 2 | 手机号框 | 输入 11 位 | - |
| 3 | 密码（≥8位，字母+数字+符号） | 输入 + 眼睛可切换 | - |
| 4 | 再次输入密码 | 输入 | 与上一致 |
| 5 | 密保问题下拉 | 选一个（12 个预设问题） | - |
| 6 | 密保答案 | 输入（**必须记住，找回密码用**） | - |
| 7 | 邀请码（选填，金色框） | 输入（如 KW138000） | **扫码/点链接打开会自动带码，无需手填** |
| 8 | 立即注册 | 点击 `doSetupAccount()` | 见下方校验逻辑 |
| 9 | 去登录 | 点击 | 切登录页 |

### 注册按钮校验逻辑（doSetupAccount）
| 情况 | 结果 |
|------|------|
| 手机号格式错 | 提示「请输入正确的11位手机号」 |
| 密码不合规 | 提示「密码需≥8位，含字母+数字+符号」 |
| 两次密码不一致 | 提示「两次密码不一致」 |
| 密保答案空 | 提示「请填写密保答案」 |
| 注册成功 | 保存账号 + **发奖励**：新用户送 30 天 VIP；带有效邀请码 → 邀请人/被邀请人各 +15 天；防作弊校验（月上限 20 人/同设备多号）；弹「恭喜！VIP 会员已到账」奖励弹窗 → 自动登录 |
| 手机号已注册 | 提示「该手机号已注册，请直接登录」 |

## 四、忘记密码页

### 元素与链路
| # | 控件 | 操作 | 结果 |
|---|------|------|------|
| 1 | × 关闭 | 点击 | 关页面回原处 |
| 2 | 手机号框 | 输入 11 位 | - |
| 3 | 密保答案 | 输入注册时设的答案 | - |
| 4 | 新密码 ×2（+ 眼睛） | 输入 | 与上一致 |
| 5 | 重置密码 | 点击 `doForgotReset()` | 见下方校验逻辑 |
| 6 | 去登录 | 点击 | 切登录页 |

### 重置校验逻辑（doForgotReset）
| 情况 | 结果 |
|------|------|
| 手机号格式错 / 密保空 / 密码不合规 / 两次不一致 | 分别提示 |
| 尝试过多被锁 | 提示「尝试次数过多，请 X 分钟后再试」 |
| 密保答案对 | 重置成功 → 提示「密码已重置」→ 回登录页用新密码登录 |
| 密保答案错 | 提示「密保答案不正确」（有尝试次数限制） |
