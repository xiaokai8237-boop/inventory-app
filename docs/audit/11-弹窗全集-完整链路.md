## A 组 · 首页/录入流程弹窗

| 弹窗 | 触发 | 按钮/元素 → 结果 |
|------|------|-------------------|
| **选筐类型**（emitGoodsSelectModal） | 发出面板「切换」/ 5 筐按钮 | 点某个筐 → 选中并进填写态；× → 关 |
| **调整回收店序**（recoverStoreOrderModal） | 手动录入（回收）「调整店序」 | ▲▼/拖动 → 换序；保存店序 → 关+提示；× → 关不保存 |
| **切换门店**（switchStoreModal） | 到店提示条「切换门店」 | 点某店 → 切换+提示+刷新输入框；取消/× → 关 |
| **AI 识图结果·请核对**（emitVoiceConfirmModal） | 拍照/语音识别完成 | 数字可改；更改▾ → 选筐；语音录入 → 录音浮层；√确定保存 → 入账保存；×取消 → 作废 |
| **保存成功**（emitSaveResultModal） | 发出保存成功 | 继续录入 → 回发出入口态；查看记录 → 跳记录页；× → 关 |
| **额外发收登记**（extraModal） | 记录页「额外发收登记」 | 5 筐额外发/收 → 保存 → 入账（所有门店）；取消/× → 关 |
| **编辑记录**（editRecordModal） | 记录列表「编辑」 | 改发/收数字 → 保存修改 → 刷新；取消 → 关 |
| **删除记录确认**（recordDeleteModal） | 记录列表「删除」 | 今日不再提醒/7天不再提醒（勾选）；确认删除 → 删；取消 → 关 |
| **生成日报**（dailyReportModal） | 记录页「生成日报」 | 线路/门店（全选/清空）/月份/报表信息 → 预览 → 日报预览弹窗 |
| **日报预览**（dailyPreviewModal） | 日报弹窗内 | 可直接改文字；返回 → 回日报；确认生成 → 生成+照片面板 |
| **上交筐照片**（photoPanelModal） | 日报确认生成后 | 拍/选照片 → 附加到日报；× → 关 |

## B 组 · 账号/数据弹窗

| 弹窗 | 触发 | 按钮/元素 → 结果 |
|------|------|-------------------|
| **恢复数据**（verifyModal） | 管理用户卡菜单「恢复数据」/ 备份面板「恢复云端数据」 | 手机号+密码 → 恢复 → 从云端拉数据到本地；取消 → 关 |
| **恢复确认**（restoreConfirmModal） | 恢复前校验通过 | 确认恢复 → 执行覆盖本地？；取消 → 关 |
| **恢复结果**（restoreResultModal） | 恢复完成 | 完成 → 关 |
| **备份结果**（backupResultModal） | 云端备份完成 | 完成 → 关 |
| **更改密码**（changePwdModal） | 账号菜单「更改密码」 | 原密码+新密码×2 → 保存；取消 → 关 |
| **注销账号**（deleteAccountModal） | 账号菜单「注销账号」 | 取消；我已知晓继续 → 第二步输密码 → 确认注销（红色警示）→ 删号 |
| **设置头像**（avatarModal） | 管理用户卡头像 | 更换头像/裁剪/滑块缩放 → 保存；× → 关 |
| **隐私政策**（privacyModal） | 注册/登录页《隐私政策》 | 不同意 → 关；同意并继续 → 关+标记 |
| **用户协议**（agreementModal） | 《用户协议》 | 我知道了 → 关 |
| **删除账号确认**（deleteConfirmModal） | 管理员删除注销账号 | 取消；确认注销 → 删除该账号数据 |
