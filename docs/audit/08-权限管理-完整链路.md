## 一、页面布局

```

│ ‹ 权限管理·到店提醒权限 [帮助?]  │
├─────────────────────────────┤
```

## 二、逐元素链路

| # | 元素 | 点击 | 结果 |
|---|------|------|------|
| 1 | ‹ 返回 | 点击 | 回管理页 |
| 2 | ？帮助 | 点击 | 弹「权限管理 · 图文帮助」 |
| 3 | 到店提醒总开关 | 点击 | 开/关切换（关后不再触发到店提醒，记账/识别不受影响） |
| 4 | 提醒设置卡（动态） | - | 含：到店距离（弹「到店提醒距离」档位选择：几百米内触发）/ 响铃 / 震动 / 静默时段开关 |
| 5 | 一键开启所有权限 | 点击 | 自动依次请求 5 项权限（位置/通知/后台/电池/自启动），用户只需点系统框「允许」 |
| 6 | 位置权限行 | 点击 | 单独请求位置权限 |
| 7 | 通知权限行 | 点击 | 单独请求通知权限 |
| 8 | 后台运行/电池优化/自启动 3 行 | 点击 | 分别引导到系统对应设置页（保活三件套） |
| 9 | 权限说明 3 块 | 无 | 纯阅读（位置/通知/保活各讲"干嘛用·什么时候用·不用会怎样·安全承诺"） |
| 10 | 数据透明 | 无 | 显示最近定位记录时间（"尚未定位记录"或最后定位时间） |

## 三、权限引导弹窗（首次进入/重看）

触发：首次用到店提醒（或从引导页）→ 弹「物流筐 · 到店提醒」引导弹窗：
- 3 张权限卡（位置/通知/后台运行），每张讲清楚用途 + 安全承诺
- 「都明白，同意并开始」→ 开始逐项请求权限
- 「不着急，稍后再说（提醒暂时不开启）」→ 关闭引导，不开启提醒
