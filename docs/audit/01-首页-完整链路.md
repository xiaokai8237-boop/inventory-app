# 物流筐 APP · 全功能交互走查 01 —— 首页（首页 tab）

> 版本：v8.2.6（2026-08-11 走查）
> 方式：逐行读代码核实，非凭记忆。APK 与网页同源（WebView 远程加载），本走查双端通用。
> 目的：每个按钮点下去会出现什么，是否符合规则，有无遗漏。

---

## 〇、首页是哪个页面

- 底部导航第一个 tab「首页」（页面 id：`page-record`）
- 进入软件默认停在这页
- **顶部「物流筐收发管理系统」标题栏只在首页显示**（需求9 已改：其他页面不显示，随滚动消失）
- 第一次打开软件会先自动弹「欢迎使用」弹窗（见 §6），关掉后看到首页

## 六、账号胶囊（登录按钮/手机号）

**未登录时**显示「登录」（人形 SVG 图标）；**已登录**显示脱敏手机号（如 138****8000）。

点击 → 弹**账号菜单**（小菜单，点别处自动关）。菜单内容分两种：

### 未登录状态（2 项）
| 菜单项 | 点击 | 结果 |
|--------|------|------|
| 登录账号 | 弹「登录账号」弹窗（输手机号+密码） |
| 设置账号密码 | 弹「设置账号密码」弹窗（注册/设密码，**此页可填邀请码，选填**） |

### 已登录状态（4 项）
| 菜单项 | 点击 | 结果 |
|--------|------|------|
| 切换用户 | 弹「登录账号」弹窗（换另一个手机号登录） |
| 更改密码 | 弹「更改密码」弹窗（输旧密码+新密码） |
| 退出登录 | 退出登录（本地登出，数据保留在云端，可重新登录恢复） |
| 注销账号 | 弹「注销账号」确认（**红色警示，确认后删除该账号所有数据**） |

**规则核对**：登录/注册/改密/注销入口齐全，符合"数据账号"设计。

## 七、两大主操作按钮（发出 / 回收）

### 「发出」按钮（金色，向上箭头图标，副标"语音 · 拍照 · 手动录入"）

点击 → `openEmitFlow()`，分三种情况：

| 情况 | 结果 |
|------|------|
| **未登录** | 弹出提示「请先登录后再录入」+ 自动弹「登录账号」弹窗 |
| **已登录但没添加店面** | 提示「请先到『店面管理』添加店面」（一闪而过） |
| **已登录且有店面** | 进入**发出面板**（§12），默认显示「入口态」：智能识别卡（拍照识别/从相册选）+ 手动录入卡（5 种筐按钮） |

### 「回收」按钮（青色，向下箭头图标，副标"语音 · 拍照 · 手动录入"）

点击 → `manualEntry('out')`，直接进入**手动录入表单**（§11）：

| 情况 | 结果 |
|------|------|
| 未登录 | **没有拦截**，直接进表单（可填数字），保存时才弹登录 |
| 已登录无店面 | 进表单，店面区显示「还没有店面，先去添加吧」提示 |
| 已登录有店面 | 进入手动录入表单：返回/调整店序 + 店面 chips + 日期 + 5 筐发出/回收输入框 + 保存按钮 |

**⚠️ 不一致发现（F-01）**：
- 发出按钮：**未登录就拦截**（弹登录）
- 回收按钮：**未登录不拦截**（放行进表单，保存时才拦）
- 同一页两个主按钮行为不一致。若按"未登录仅可查看"的规则，回收按钮应在点击时就提示登录。

## 八、今日状态卡

**纯展示，无按钮**（点击无反应）。内容：
- 标题「今日状态」+ 当天日期
- 5 种筐各一行的「发出/回收」数字表
- 右侧「已录店面 X/N」数字
- 「录入进度」百分比进度条
- 每家店一个状态小圆片（绿=已录 / 灰白=待录）
- 底部提醒：还有 X 家店未录入（列出店名）/ 今日所有店面均已录入 / 今日还没有记录

**⚠️ P0-1 emoji 违规发现（F-02）**：「还有 X 家店未录入」前面用 `⏳`（沙漏 emoji，U+23F3）作图标——违反"禁止 emoji 作功能图标"规则（2026-08-10 全站清理时遗漏，因 ⏳ 不在检测正则覆盖范围内）。

## 十一、手动录入表单（点「回收」进入）

顶部栏：`← 返回` + 标题「回收 - 手动录入」+ （仅回收时显示）「调整店序」

| 按钮/控件 | 点击/操作 | 结果 |
|-----------|-----------|------|
| ← 返回 | 回到首页向导（今日状态自动刷新） |
| 调整店序（仅回收） | 弹「调整回收店序」弹窗（见 §13） |
| 到店提示条「切换门店」（定位到店才出现） | 弹「切换门店」弹窗（见 §14） |
| 店面 chips（一串店面按钮） | 点某店 → 切换当前录入店面，输入框刷新成该店当日数据；当前店高亮 |
| 日期（默认今天，可改） | 改日期 → 输入框刷新成该日期该店的数据 |
| 5 筐「发出/回收」数字框 | 输入数量 |
| 「保存当日记录」 | 见下方保存逻辑 |

**保存逻辑（saveManualRecord）**：
| 情况 | 结果 |
|------|------|
| 未登录 | 提示「请先登录后再录入」+ 弹登录 |
| 没选日期 | 提示「请选择日期」 |
| 没添加店面 | 提示「请先到『店面管理』添加店面」 |
| 全填 0 | 提示「请至少填一项数量」 |
| 正常 | 保存成功 → 提示「保存成功」→ **自动跳到下一家店**（连续录入），跳到最后一店后停在本店清空输入 |

**规则核对**：符合"一步保存 + 自动下一家"设计。

## 十二、发出面板（点「发出」进入）

顶部：`← 返回` + 标题「发出」；第二行：记录日期（默认今天，可改历史日期补录）。

### 入口态（默认显示）
**智能识别卡**：
| 按钮 | 点击 | 结果 |
|------|------|------|
| 拍照识别 | 调起系统拍照/相册选择器（**两按钮同一行为**，见 F-03） |
| 从相册选 | 同上（调起系统选择器） |

**手动录入卡**：5 种筐按钮（鲜食/面包/冷藏/冷冻/常温，各带 SVG 图标）→ 点某个筐 → 切到**填写态**。

### 填写态（选筐后）
| 按钮/控件 | 点击/操作 | 结果 |
|-----------|-----------|------|
| 顶部筐名 +「切换」按钮 | 弹「选择发出的筐类型」弹窗（见 §15） |
| 语音录入按钮 | 弹**录音浮层**（见 §17），说完数字点「结束」→ AI 识别 → 弹「AI 识图结果 · 请核对」弹窗（见 §16） |
| 各家店数字输入框（每家店一行，常温筐有两框：整箱数+物流箱） | 输入数量；键盘「确定/Enter」自动跳下一家店（常温筐先跳整箱再跳物流箱，最后跳保存按钮） |
| 保存发出 | 见下方保存逻辑 |

**保存逻辑（saveEmitRecords）**：
| 情况 | 结果 |
|------|------|
| 没选筐 | 提示「请先选择筐类型」 |
| 全填 0 | 提示「请至少填一家店的数量」 |
| 正常 | 保存 → 首页今日状态/明细刷新 → 弹「保存成功」弹窗（§18） |

## 十三、弹窗：调整回收店序

触发：手动录入表单（回收模式）顶部「调整店序」。
内容：所有店面列表，每行 = 店名 + 编号徽标 + ▲/▼ 按钮，支持**按住拖动**换序。
| 按钮/操作 | 结果 |
|-----------|------|
| ▲ / ▼ | 该店上移/下移一格 |
| 拖动行 | 拖到目标位置松手换序 |
| 保存店序 | 关弹窗，提示「回收店序已更新（仅回收页）」，店序只影响回收录入页 |
| × / 遮罩 | 关弹窗（不保存） |

## 十五、弹窗：选择发出的筐类型

触发：发出面板填写态顶部「切换」按钮，或进入填写态前的 5 筐按钮。

## 十六、弹窗：AI 识图结果 · 请核对

触发：发出面板拍照识别完成 / 语音识别完成。
内容：
- 记录日期（默认今天，可改历史日期补录）
- 筐类型（AI 自动识别，旁边「更改 ▾」可换筐）
- 店名 + 识别数字列表（**数字可点开直接改**；绿色=高置信，黄色=建议核对）
- 顶部说明「绿色=高置信 黄色=建议核对 数字可点开直接改」
- 合计行（常温筐显示整箱+物流箱两个合计）
- 底部警示「请核对好每行数据后再点『确定保存』，保存后直接入账」
- 弹窗内「语音录入」按钮（识别不准时说话补救，点后弹录音浮层 §17）

| 按钮 | 点击 | 结果 |
|------|------|------|
| 更改 ▾ | 弹筐类型选择弹窗（§15） |
| 数字框修改 | 直接改数字，合计自动重算 |
| 记录日期 | 可改（改后同步发出面板日期） |
| × 取消 | 关弹窗，本次识别结果作废 |
| √ 确定保存 | **分两种情况**：① 拍照识别 → 按识别行直接入账保存（未匹配到店面管理的店 → 暂存 + 提示"X 家未录入未保存，请先去店面管理添加"）；② 语音识别 → 数字填入发出页输入框 → **自动保存入账**（不再二次点保存）→ 都弹「保存成功」（§18） |

**规则核对**：符合"AI 识别可修改 + 保存直接入账"设计。
