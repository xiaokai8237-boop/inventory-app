## 二、逐按钮链路

| # | 元素 | 点击 | 结果 |
|---|------|------|------|
| 1 | ‹ 返回 | 点击 | 回管理页 |
| 2 | ？帮助 | 点击 | 弹「邀请好友 · 图文帮助」 |
| 3 | 未登录引导「去登录」 | 点击 | 切登录页 |
| 4 | 复制邀请码 | 点击 | 未登录→提示请先登录；正常→复制 KW 码 + 提示 |
| 5 | 复制链接+文案 | 点击 | 未登录→提示；正常→**复制「随机一条邀请文案 + 专属链接」**（链接含 ?invite=码） |
| 6 | 邀请记录入口 | 点击 | 跳**邀请记录页**（见 §四） |
| 7 | 生成邀请海报 | 点击 | 未登录→弹「请先登录」引导弹窗（去登录/稍后再说）；已登录→弹**海报弹窗**（见 §三） |
| 8 | 分享到微信/朋友圈 | 点击 | 未登录→提示；正常→手机支持分享面板则弹系统分享；不支持→复制文案+链接兜底 |

## 三、弹窗：拉新海报（7 款随机）

| 元素 | 点击 | 结果 |
|------|------|------|
| 换一张 | 随机换另一款（不重复当前） |
| 海报图片 | 无（加载中显示「海报生成中…」） |
| 下载海报 | Canvas 合成（**左上角覆盖个人邀请码二维码**）→ 保存 JPEG 到相册/下载 |
| 转发 | 手机支持 → 弹系统分享（图片文件）；不支持 → 复制文案+链接兜底 |
| 关闭 | 关弹窗 |

**关键**：海报二维码是**你自己的邀请码**（扫码直接带码），7 款底图（深蓝/青蓝/墨绿/藏蓝/黑金/2张带码版）进邀请页时已**预加载**，点击秒开。

## 四、邀请记录页

| 元素 | 点击 | 结果 |
|------|------|------|
| ‹ 返回 | 回邀请好友页 |
| ？帮助 | 弹「邀请记录 · 图文帮助」 |
| 未登录引导「去登录」 | 切登录页 |
| 记录列表 | 无（纯展示） | 每条：脱敏手机号（138\*\*\*\*8001）+ 注册时间 + 状态徽标（**已发放 +15天** 绿底 / **待发放** 红描边）；副标题「本月 X/20 人 · 每成功 1 人 +15 天 VIP」 |
| 空状态「去邀请好友」 | 点击 | 回邀请好友页 |

**数据来源**：云端 `/api/invite/records`（按邀请人过滤 + 脱敏 + 时间倒序）。

## 五、邀请奖励规则（对照核验）

| 规则 | 实现状态 |
|------|----------|
| 新用户注册送 30 天 | ✅ 注册即发 |
| 邀请人 +15 天 / 被邀请人 +15 天 | ✅ 带有效邀请码注册时发 |
| 邀请码 = KW + 手机号后 6 位 | ✅ |
| 链接/扫码自动带码 | ✅（?invite= 参数） |
| 注册页邀请码选填（手动通道） | ✅（手动填 > URL 参数） |
| 防作弊：月上限 20 人 | ✅（达上限邀请奖励 denied，新用户 30 天照发） |
| 防作弊：同设备多账号检测 | ✅（同设备 ≥2 账号后带码注册 deny） |
| 邀请记录页 | ✅ |

## 六、审计发现

| 编号 | 内容 | 级别 |
|------|------|------|
| F-51 | 邀请记录页「待发放」徽标实际很少出现（发奖是注册时实时完成的）——"待发放"状态几乎不可见 | 观察（防作弊 denied 时显示） |
