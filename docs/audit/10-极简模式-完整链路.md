## 一、模式选择页（标准/极简切换总入口）

```
┌─────────────────────────────┐
│ ‹ 模式选择                   │
│ 选一个模式，随时可切换 · 数据互不影响 │
│ ┌─────────────────────────┐ │
│ │ 标准模式（当前使用中）       │ │
│ │ 按门店明细·逐店录入·全功能   │ │
│ │ [切换到标准]              │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 极简模式（未使用）          │ │
│ │ 只记总数·不选店·最快       │ │
│ │ [切换到极简]              │ │
│ └─────────────────────────┘ │
│ 切换后立即生效，数据互不影响    │
└─────────────────────────────┘
```

| # | 元素 | 点击 | 结果 |
|---|------|------|------|
| 1 | ‹ 返回 | 点击 | 回原页面（管理页或极简设置页） |
| 2 | 切换到标准 | 点击 | 切标准模式 → 跳标准首页（当前已是标准则按钮置灰/显示当前使用中） |
| 3 | 切换到极简 | 点击 | 切极简模式 → 跳极简首页 |

**进入方式**：管理页「模式选择」/ 极简设置页「界面风格」。

## 二、极简首页（极简录入）

```
┌─────────────────────────────┐
│ 极简录入        [帮助?] [登录]│
│ 记录日期 [2026-08-11]        │
│ 几点发出 [时间] 默认当前·可改  │
│ 5 筐 发出/回收 输入区         │
│ [ 保存 ]                    │
└─────────────────────────────┘
```

| # | 元素 | 操作 | 结果 |
|---|------|------|------|
| 1 | ？帮助 | 点击 | 弹「极简录入 · 图文帮助」 |
| 2 | 登录胶囊 | 点击 | 弹登录 |
| 3 | 记录日期 | 改日期 | 刷新该日已有数据 |
| 4 | 几点发出 | 改时间 | 默认当前时间，可改 |
| 5 | 5 筐发出/回收框 | 输入数量 | 每筐两框（发出/回收总数） |
| 6 | 保存 | 点击 | 未登录→弹登录；全空→提示；正常→保存极简记录 + 提示成功 |

**关键**：极简数据与标准模式**分开存**（独立 key），互不影响。

## 三、极简记录页

```
┌─────────────────────────────┐
│ 极简记录        [帮助?] [登录]│
│ 从 [日期时间] 至 [日期时间]   │
│ 筐类型 | 发出 | 回收 | 差额   │
│ 鲜食/面包/冷藏/冷冻/常温 5 行  │
└─────────────────────────────┘
```

| # | 元素 | 操作 | 结果 |
|---|------|------|------|
| 1 | 从/至 时间 | 改范围 | 表格按范围刷新 |
| 2 | 表格 | 无 | 每筐：发出合计 / 回收合计 / **差额（回收-发出）** |
| 3 | 空状态 | 无 | 「这个时间段还没有记录，去首页录入吧」 |
