## 一、汇总页布局

```
┌─────────────────────────────┐
│ [帮助?]                      │
│ 汇总日期范围 [起] ~ [止]      │
│ 单店汇总（全部店下拉）         │
│ [近3天] [近30天] [全部]       │
├─────────────────────────────┤
│ 汇总表格（动态）              │ ← 每种筐 发出/回收/差异
└─────────────────────────────┘
```

进入方式：管理页「汇总」（VIP 功能，测试期放行）。

## 二、汇总页逐元素链路

| # | 元素 | 操作 | 结果 |
|---|------|------|------|
| 1 | ？帮助 | 点击 | 弹「汇总 · 图文帮助」 |
| 2 | 开始日期 / 结束日期 | 选日期 | 表格按范围刷新 |
| 3 | 店面下拉 | 选店/全部店 | 表格刷新（单店或全店汇总） |
| 4 | 近3天 | 点击 | 日期范围自动设为最近 3 天 → 刷新 |
| 5 | 近30天 | 点击 | 日期范围自动设为最近 30 天 → 刷新 |
| 6 | 全部 | 点击 | 清空日期范围（全部数据）→ 刷新 |
| 7 | 汇总表格 | 无 | 每行一种筐：发出合计 / 回收合计 / 差异数 |

## 三、对账页布局

```
┌─────────────────────────────┐
│ 导出我的数据                  │
│ 导出日期范围 [起] ~ [止]      │
│ 店面（全部店下拉）            │
│ [导出明细] [导出汇总]         │
└─────────────────────────────┘
```

进入方式：管理页「对账」（VIP 功能，测试期放行）。

## 四、对账页逐元素链路

| # | 元素 | 操作 | 结果 |
|---|------|------|------|
| 1 | 开始/结束日期 | 选日期 | - |
| 2 | 店面下拉 | 选店/全部店 | - |
| 3 | 导出明细 | 点击 | 按日期+店面导出**逐条明细** Excel（含每条记录）→ 提示「Excel已导出（按日分组）」 |
| 4 | 导出汇总 | 点击 | 导出**汇总表** Excel（每种筐发/收/差异）→ 保存文件 |

**导出文件处理**：生成 Excel 文件 → 触发下载（APK 内保存到手机 / 浏览器下载）。
