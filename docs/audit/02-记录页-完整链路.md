# 物流筐 APP · 全功能交互走查 02 —— 记录页（记录 tab）

> 版本：v8.2.6（2026-08-11 走查）· 逐行读代码核实

---

## 一、页面布局

```
┌─────────────────────────────┐
│ [帮助?] 日期 | 店面 | 筐筛选   │ ← 筛选区
│   [全部]  [仅今天]            │
├─────────────────────────────┤
│ [生成日报]                   │
│ [额外发收登记]               │
├─────────────────────────────┤
│ 历史记录列表（动态）           │ ← 每条可编辑/删除
└─────────────────────────────┘
```

## 二、逐按钮链路

| # | 控件 | 点击/操作 | 结果 |
|---|------|-----------|------|
| 1 | 右上角 ？帮助 | 点击 | 弹「记录 · 图文帮助」（筛选/日报/额外发收/编辑删除说明） |
| 2 | 日期框 | 选日期 | 列表按该日期筛选（空=全部日期） |
| 3 | 店面下拉 | 选店 | 列表按店筛选（含"全部店"） |
| 4 | 筐下拉 | 选筐 | 列表按筐筛选（5 种筐 + 全部） |
| 5 | 全部按钮 | 点击 | 清空三个筛选，显示全部记录 |
| 6 | 仅今天按钮 | 点击 | 日期自动设为今天，只显示今天的 |
| 7 | 生成日报 | 点击 | 弹「生成日报」弹窗（见 §三） |
| 8 | 额外发收登记 | 点击 | 弹「额外发收登记」弹窗（见 §四） |
| 9 | 历史列表·编辑 | 点击某条「编辑」 | 弹「编辑记录」弹窗（见 §五） |
| 10 | 历史列表·删除 | 点击某条「删除」 | 弹「删除确认」弹窗（见 §六） |
| 11 | 历史列表·记录行 | 点击整行 | **无反应**（只能点编辑/删除按钮） |

## 三、弹窗：生成日报

触发：记录页「生成日报」。
内容：选线路（chips）/ 选门店（默认全选，可取消勾选）+ 全选/清空按钮 / 选月份 / 报表信息勾选（各店发出·各店回收·今日回框·本月累计回框）。

| 按钮 | 点击结果 |
|------|----------|
| 全选 / 清空 | 勾选/取消所有门店 |
| （预览生成） | 弹「日报预览」弹窗 |
| × | 关弹窗 |

**日报预览弹窗**：文字日报内容（可直接修改文字）→ 「返回」关弹窗 / 「确认生成」→ 生成日报 → 弹「上交筐照片」面板（拍/选照片）→ 确认后日报生成完成。

---

## 四、弹窗：额外发收登记

触发：记录页「额外发收登记」（补录没进店面的散筐）。
内容：表格 = 5 种筐各一行「额外发出 / 额外回收」数字框。
| 按钮 | 点击结果 |
|------|----------|
| 保存 | 未登录→弹登录；没填数→提示；正常→保存入账（记到"所有门店"，首页今日状态会显示"含额外发收"）→ 关弹窗 |
| × / 取消 | 关弹窗（不保存） |

---

## 五、弹窗：编辑记录

触发：历史列表某条「编辑」。
内容：该记录的店面/日期/筐 + 「发出」「回收」两个数字框（预填原值）。
| 按钮 | 点击结果 |
|------|----------|
| 保存修改 | 校验→保存新数量→列表刷新→关弹窗 |
| 取消 | 关弹窗（不改） |

---

## 六、弹窗：删除确认（防误删）

触发：历史列表某条「删除」（删除记录）：
| 情况 | 结果 |
|------|------|
| 7 天内已确认过 | 直接删除（不再弹窗） |
| 未确认过 | 弹「删除确认」弹窗 |

弹窗内容：红色警示「确定要删除这条记录吗？删除后不可恢复」+ **不再提醒**选项（今日不再提醒 / 7 天不再提醒）。
| 按钮 | 点击结果 |
|------|----------|
| 确认删除 | 删除该条 → 列表刷新 |
| 取消 | 关弹窗（不删） |

## 七、审计发现

| 编号 | 内容 | 级别 |
|------|------|------|
| F-11 | 记录列表整行点击**无反应**（只能点小字"编辑/删除"）——整行可点区域小，误触率低但可点性差 | 建议优化 |
| F-12 | 「生成日报」流程较长（日报弹窗→预览→照片面板 3 层），首次使用易迷路 | 观察 |
