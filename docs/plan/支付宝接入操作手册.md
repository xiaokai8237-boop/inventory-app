# 支付宝手机网站支付 · 签约接入操作手册（保姆级）

> 适用项目：物流筐收发管理系统（v8.2.16 起）
> 编写：2026-08-11
> 目的：让没有技术背景的老板，照着做就能把支付宝收款通道开通，实现"用户付完钱 → VIP 自动到账"
> 前置：代码已开发完成并上线，**只差你完成本手册的支付宝侧配置**

## 一、你需要准备的 3 样东西（本手册教你怎么拿）

| 序号 | 名称 | 长什么样 | 用途 |
|------|------|----------|------|
| 1 | APPID | 一串数字，如 2021007123456789 | 标识你的应用 |
| 2 | 应用私钥（PKCS8） | 以 `-----BEGIN PRIVATE KEY-----` 开头的一长串 | 代码签名用（**保密**） |
| 3 | 支付宝公钥 | 以 `-----BEGIN PUBLIC KEY-----` 开头的一长串 | 代码验签用 |

> 拿到这 3 个值后发给我，我填进系统配置，就能正式收款。

## 二、第一步：注册支付宝开放平台（10 分钟）

1. 手机或电脑打开浏览器，访问 **https://open.alipay.com**
2. 点右上角「登录」→ 用**你要收款的支付宝账号**扫码登录（建议用收钱的那个号，别用临时号）
3. 首次登录会让你**实名认证**：按提示填真实姓名、身份证号，扫脸确认
   - 必须和你支付宝账号的实名一致，否则后面签约不通过
4. 实名完成后，进入开放平台首页

> 电脑操作建议用 Chrome 或 Edge 浏览器；全程不需要营业执照、不需要花钱。

---

## 三、第二步：创建应用（10 分钟）

1. 登录开放平台后，顶部或首页找到 **「控制台」**，点进去
2. 左侧菜单点 **「网页 & 移动应用」**（有的版本叫"应用中心"）
3. 点 **「创建应用」**（或「立即创建」）
4. 应用类型选择：**「网页应用」**（注意：不是小程序，不是移动应用）
   - 网页应用 = 手机网站支付（H5），正是我们需要的
5. 填写：
   - **应用名称**：填"物流筐" 或 "物流筐收发管理"（随便起，能认出来就行）
   - **应用图标**：上传一个正方形图片（没有的话随便传一张，审核不是重点）
6. 点「确认创建」→ 创建成功后会显示一个 **APPID**（一串数字）
   - **马上复制保存到备忘录**，这就是第 1 样东西
7. 创建后应用状态是"沙箱/未上线"，正常，我们下一步签约能力

---

## 四、第三步：添加并签约「手机网站支付」能力（10 分钟）

1. 在刚创建的应用详情页，找到 **「产品绑定」** 或 **「能力列表」** / **「添加能力」**
2. 搜索 **「手机网站支付」**（也叫 WAP 支付，接口名 alipay.trade.wap.pay）
3. 点「添加能力」→ 再点 **「签约」**（有的版本是"开通"）
4. 签约时系统会让你选场景，选择 **「手机网站（H5）未上线」** 通道：
   - 上传 **3 张页面截图**（这是未上线通道的硬性要求，缺一不可）：
     1. **首页截图**：APP 登录后的首页样子
     2. **商品/服务页截图**：会员中心页（能看到 4 个档位价格的那页）
     3. **支付页面截图**：点"开通月卡"后弹出的样子（当前会提示测试期说明，截图即可）
   - 截图从哪来：手机打开 APP 截屏，或电脑浏览器打开 https://inventory-app-9ql.pages.dev 截屏
   - 格式：jpg/png，单张 ≤5MB
5. 提交后等审核：**一般 1-3 个工作日**，快的话当天过
6. 审核通过后，该能力状态变为「已开通」

> 备注：审核通过后你有 **30 天时间**完成正式上线提额。期间收款额度有限（单笔 ≤2000 元，够用——我们的档位最高才 158 元）。之后若需要更高额度，补全资质提额即可。

## 五、第四步：生成密钥（15 分钟，最关键）

支付宝接口用"公钥 + 私钥"配对验签，需要你生成一对。**用支付宝官方工具最省事**：

### 方法 A：用支付宝官方密钥工具（推荐，最简单）

1. 打开 **https://opendocs.alipay.com/common/02kipl**（支付宝开放平台"密钥工具"下载页）
2. 下载对应系统的 **「支付宝开放平台密钥工具」**（Windows 版）
3. 打开工具 → 点 **「生成密钥」** → 工具自动生成一对：
   - **应用私钥**（pkcs8 格式）——**复制保存好，这是第 2 样东西，绝对保密，别发给任何人**（发我的是用来对接的，也只发我这里）
   - **应用公钥** —— 工具里点「复制公钥」备用
4. 回到开放平台 → 你的应用详情 → **「开发设置」→「接口加签方式」**
5. 加签方式选 **「公钥模式」**（或 RSA2）→ 把刚才复制的**应用公钥**粘贴进去 → 保存
6. 保存后，页面会显示 **「支付宝公钥」**——**复制保存，这是第 3 样东西**
   - 注意区分：**应用公钥是你生成并粘贴上去的**；**支付宝公钥是支付宝给你的**，两个不一样

### 方法 B：命令行生成（懂电脑的人用）

```bash
openssl genrsa -out app_private_key.pem 2048
# 转 PKCS8（支付宝要求格式）
openssl pkcs8 -topk8 -nocrypt -in app_private_key.pem -out app_private_key_pkcs8.pem
# 取公钥
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem
```
- `app_private_key_pkcs8.pem` 内容 = 应用私钥（第 2 样）
- `app_public_key.pem` 内容 = 应用公钥（粘贴到开放平台）
- 粘贴应用公钥后，开放平台显示的"支付宝公钥" = 第 3 样

## 八、常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 一定要备案域名吗？ | 未上线通道审核通过后有 30 天过渡期可用；长期正式收款建议补一个备案域名（约 60 元/年，备案 1-2 周），到时告诉我，我帮你切换回调地址 |
| 手续费多少？ | 支付宝官方 0.6%（每笔 12.8 元收 0.077 元），无月租 |
| 钱什么时候到账？ | 新签约 90 天内次日结算到支付宝余额；满 90 天可实时到账 |
| 用户付完没到账怎么办？ | APP 会员中心有"我已支付未到账"申诉入口（后续补做），也可直接联系管理员人工补发 |
| 可以退款吗？ | 暂不做在线退款；有需求可联系管理员人工原路退 |
| 微信支付什么时候上？ | 支付宝跑通后推进（微信需认证服务号+商户号+备案，流程较长，详见《支付接入规划.md》） |
